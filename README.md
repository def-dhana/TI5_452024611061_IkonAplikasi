# Change Icon App

Aplikasi Android menggunakan Jetpack Compose untuk demonstrasi perubahan ikon aplikasi (Change App Icon)

## Instalasi

1. Clone repository ini
   ```bash
   git clone https://github.com/NaufalAhnafussidqi/Change-Icon-App.git
   ```
2. Buka project di Android Studio
3. Sinkronkan Gradle dan build project
4. Jalankan aplikasi pada emulator atau perangkat fisik

## Penggunaan

1. Buka aplikasi Change Icon App
2. Pilih ikon yang diinginkan dari daftar yang tersedia
3. Konfirmasi perubahan ikon
